# Sushi Tomi

Modern Next.js rebuild of [sushitomi.us](https://sushitomi.us/) - authentic Japanese sushi restaurant in Mountain View, California.

## Stack

- Next.js App Router + TypeScript + Tailwind CSS
- shadcn/ui primitives
- Deployed on Vercel

## Local development

```bash
npm install
npm run dev
```

App runs at [http://127.0.0.1:43155](http://127.0.0.1:43155).
